# 資訊判讀與事實查核技能

## 目的
當使用者提供一則新聞報導、文章、故事或聽聞的訊息，使用 web_search 主動查證，並透過 4 個步驟評量訊息可信度，依重大程度列舉可疑段落。

**語言規則**：輸出語言需配合使用者輸入語言。使用者用繁體中文輸入，以繁體中文回應；使用者用英文輸入，以英文回應；以此類推。

---

## 啟動條件
當以下情況發生時，啟動此技能：
- 使用者貼上新聞連結或內文
- 使用者問「這是真的嗎？」「這真的假的？」「請查核可信度」
- 使用者分享社交媒體平台上的訊息
- 使用者質疑一則文章的真假
- User pastes an article, claim, or link and asks "is this real?", "fact check this", "verify this"

---

## 工作流程

**重要**：在分析前，先主動使用 `web_search` 查證關鍵聲稱。搜尋策略：
1. 搜尋文章中的具體人名、數據、事件
2. 搜尋是否有已知事實查核機構（如台灣事實查核中心、Snopes、Reuters fact check、AFP Fact Check）針對此訊息發布報告
3. 搜尋原始來源（若文章聲稱引用某研究或報告，直接搜尋該研究）
4. 如有連結，用 `web_fetch` 取得完整內容

---

### 第 1 步：拆解訊息，分清「事實」及「觀點」

列出訊息中所有：
- **事實性聲稱**：可被驗證的具體陳述（數據、事件、引言、因果關係）
- **觀點/意見**：無法客觀驗證的立場或評論
- **混淆之處**：以觀點偽裝成事實的陳述

---

### 第 2 步：查證「資訊來源」及「事實內容」

針對第 1 步列出的每項**事實性聲稱**，分析：

- 其**資訊來源**有無以下情形
  - 沒有提供來源
  - 無法證實的來源
  - 錯誤來源
  - 來源不具專業背景
  - 經驗來源不可信
  - 假造來源
- 其**事實內容**有無以下情形
  - 無法證實的內容
  - 包含錯誤內容
  - 變造內容
- 其**擴散行為**有無以下情形
  - 多個帳號在短時間內同步發布高度相似的內容

分析時，使用 `web_search` 查證：
- 來源是否真實存在且具可信度？
- 內容是否與原始來源一致？
- 是否有其他可信來源可以佐證或反駁？
- 搜尋該訊息的原文關鍵句，觀察是否有跨平台同步現象

記錄每項查證結果，附上查到的 URL。

---

### 第 3 步：從「事實」到「觀點」，檢驗推論過程

針對連結第 1 步列出的**事實性聲稱**到**觀點**之間的**推論過程**，分析有無以下情形：

- 尚待科學驗證
- 不當因果關係
- 不當訴諸權威
- 引起情緒
- 沒有證據
- 證據不足
- 沒有因果關係
- 選擇性剪輯
- 以偏概全
- 錯誤類比
- 邏輯錯誤
- 陰謀論

---

### 第 4 步：判定訊息可信度

根據上述分析，為該訊息標記適用標籤：

| 類別         | 可疑標籤                                                                     | 資訊操弄標籤                                                                              |
|--------------|------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| **資訊來源** | 沒有提供來源 / 無法證實的來源 / 錯誤來源 / 來源不具專業背景 / 經驗來源不可信 | 假造來源                                                                                  |
| **事實內容** | 無法證實的內容                                                               | 包含錯誤內容 / 變造內容                                                                   |
| **擴散行為** | 多個帳號在短時間內同步發布高度相似的內容                                     |                                                                                           |
| **推論過程** | 尚待科學驗證 / 不當因果關係 / 不當訴諸權威 / 引起情緒                        | 沒有證據 / 證據不足 / 沒有因果關係 / 選擇性剪輯 / 以偏概全 / 錯誤類比 / 邏輯錯誤 / 陰謀論 |


**判定規則：**
- 無任何標籤 → **大致可信**
- 有 1 個以上「可疑標籤」→ **可疑訊息**
- 有 1 個以上「資訊操弄標籤」→ **資訊操弄**

---

## 輸出格式

輸出需包含：

1. **總體判定**（大致可信 / 可疑訊息 / 資訊操弄），並說明信心程度（高 / 中 / 低）
2. **標籤清單**：列出所有適用標籤，每個標籤附上：
   - 對應的原文段落
   - 查證結果與簡要判斷理由
   - 相關來源 URL（若有）
3. **查核摘要**：2–4 句話總結整體發現

若使用者輸入為英文，以上格式改用英文輸出，標籤名稱亦翻譯為英文。

---

## 🚨 詐騙訊息偵測

若查核過程中發現訊息可能涉及詐騙（要求匯款、提供個資、下載軟體、私下聯繫等），請額外進行以下分析：

1. **急迫性檢查**：是否有時間壓力語言？
2. **管道驗證**：是否通過官方管道聯繫？
3. **請求分析**：是否要求金錢或個人資料？
4. **私下聯繫**：是否要求脫離正式管道？

輸出時增加「🚨 詐騙風險評估」區塊，包含風險等級與建議行動。

詳細詐騙類型參考：`references/scam-checklist.md`

---

## 注意事項
- 不要在沒有多個權威事實查核機構同意的情況下，直接宣稱某訊息為「假新聞」
- 對於科學或醫學議題，以學術共識為準，而非單一研究
- 查不到足夠資訊時，誠實說明「無法確認」，而非猜測
