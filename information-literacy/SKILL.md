# 資訊判讀與事實查核技能

## 目的

當使用者貼上一則新聞報導、文章、故事或聽聞而來的訊息，用 4 個步驟評量訊息可信度，依重大程度列舉出其中可疑的段落。

## 啟動條件

當以下情況發生時，啟動此技能：

- 使用者貼上一則新聞連結或內文
- 使用者問「這是真的嗎？」或「這真的假的？」或「請你查核可信度」
- 使用者分享社交媒體平台上的訊息
- 使用者質疑一則文章的真假

## 工作流程

### 第 1 步，拆解訊息，分清「事實」及「觀點」

### 第 2 步，查證「資訊來源」及「事實內容」是否正確且完整

### 第 3 步，從「事實」到「觀點」，檢驗推論過程是否合理

### 第 4 步，判定訊息可信度

根據上述分析步驟，列舉該訊息是否帶有以下標籤：

|          | 可疑標籤           | 資訊操弄標籤   |
|----------|--------------------|----------------|
| 資訊來源 | - 沒有提供來源     | - 假造來源     |
|          | - 無法證實的來源   |                |
|          | - 錯誤來源         |                |
|          | - 來源不具專業背景 |                |
|          | - 經驗來源不可信   |                |
|----------|--------------------|----------------|
| 事實內容 | - 無法證實的內容   | - 包含錯誤內容 |
|          |                    | - 變造內容     |
|----------|--------------------|----------------|
| 推論過程 | - 尚待科學驗證     | - 沒有證據     |
|          | - 不當因果關係     | - 證據不足     |
|          | - 不當訴諸權威     | - 沒有因果關係 |
|          | - 引起情緒         | - 以偏概全     |
|          |                    | - 錯誤類比     |
|          |                    | - 邏輯錯誤     |
|          |                    | - 陰謀論       |

接下來：

- 如果這則訊息沒有任可「可疑標籤」或「資訊操弄標籤」，則可判定為「大致可信」。
- 如果這則訊息有 1 個以上的「可疑標籤」，則可判定為「可疑訊息」。
- 如果這則訊息有 1 個以上的「資訊操弄標籤」，則可判定為「資訊操弄」。

輸出上述判定，包含所有對該訊息所下的標籤，以及所有標籤的相關段落與簡要的判斷過程。
